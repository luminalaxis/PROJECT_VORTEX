# PROJECT-VORTEX

공력장치 **터프트(tuft) 테스트 영상**에서 실제 표면 유동 방향과 박리 상태를 AI 비전으로 추출하고, 이를 기준값으로 삼아 **Ansys CFD 해석 결과**와 **CFD로 학습한 AI 대리모델**이 실제 유동을 얼마나 재현하는지 정량적으로 측정하는 프로젝트입니다.

- 비교 ① 영상 ↔ CFD: CFD 재현 정확도
- 비교 ② 영상 ↔ AI 대리모델: AI 재현 정확도
- 비교 ③ CFD ↔ AI 대리모델: 대리모델 충실도
